Ты — senior-разработчик. Напиши на {{LANG}} консольную утилиту, которая читает Excel-файл с продажами, чистит данные, считает агрегаты и строит графики. Код должен быть промышленного качества: читаемый, покрытый тестами, с понятными ошибками.

## Вход
Файл `data/sales.xlsx` (уже лежит в каталоге проекта), два листа.

Лист `Sales`, первая строка — заголовок:
`order_id, order_date, region, category, product, manager, quantity, unit_price, discount`

Лист `Targets`: `region, month (YYYY-MM), target` — план выручки по региону и месяцу.

## Правила очистки (обязательны, по ним проверяется результат)
1. Полностью пустые строки игнорируются: они не считаются ни валидными, ни пропущенными.
2. Дубликаты `order_id`: обрабатывается только первое вхождение (даже если оно окажется невалидным), остальные считаются пропущенными (skipped).
3. `order_date` — дата Excel или текст `DD.MM.YYYY`. Если не разбирается, строка пропускается.
4. `quantity` — целое > 0. Пусто, текст, ноль или отрицательное значение → строка пропускается.
5. `unit_price` — число > 0. Допускается текст с точкой или запятой как десятичным разделителем (`"1234,50"`, `"1234.5"`). Если не разбирается, строка пропускается.
6. `discount` — доля от 0 до 1 или текст с процентом (`"15%"` → 0.15). Пусто → 0.
7. `region` — обрезать пробелы по краям.
8. Выручка строки = `quantity * unit_price * (1 - discount)`. Суммировать с полной точностью, округлять до 2 знаков только при выводе.

## Выход
Команда: `<запуск> --input data/sales.xlsx --out out/`

В каталоге `out/`:
- `summary.json` — строго такой структуры (ключи-словари отсортированы по ключу):
```json
{
  "valid_rows": 0, "skipped_rows": 0, "total_revenue": 0.0,
  "revenue_by_month": {"2025-01": 0.0},
  "revenue_by_region": {"Москва": 0.0},
  "revenue_by_category": {"Книги": 0.0},
  "top_products": [{"product": "…", "revenue": 0.0, "quantity": 0}],
  "plan_vs_fact": [{"region": "…", "fact": 0.0, "target": 0.0, "completion_pct": 0.0}]
}
```
  - `top_products` — 10 товаров по убыванию выручки; при равенстве — по названию.
  - `plan_vs_fact` — по каждому региону сумма за год, регионы по алфавиту. `completion_pct = fact / target * 100`.
- PNG-графики (подписи на русском, читаемые оси, заголовки, формат чисел с разделителями тысяч):
  1. `revenue_by_month.png` — линия выручки по месяцам;
  2. `revenue_by_region.png` — столбцы по регионам;
  3. `category_share.png` — круговая или кольцевая диаграмма долей категорий;
  4. `top_products.png` — горизонтальные столбцы, топ-10;
  5. `plan_vs_fact.png` — сгруппированные столбцы «план/факт» по регионам.
- `report.html` — одна страница со всеми графиками и ключевыми цифрами.

## Требования

- Тесты: модульные на каждое правило очистки и на агрегаты; интеграционный — прогон на `data/sales.xlsx`, проверка структуры `summary.json` и наличия всех PNG.
- Линтер или форматтер языка без замечаний.
- `README.md`: установка, запуск, примеры.
- Используй стандартные или популярные библиотеки экосистемы.
