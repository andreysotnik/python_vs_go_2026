# Журнал работы

## Этапы

1. **Чтение ТЗ и данных** — `data/sample.tsv` (20 строк, 10/10). Проектирование под RE2 (без lookaround):
   слово-токен → варианты нормализации → правила по корням с якорями и приставками.
2. **Реализация** — `profanity/rules.go`, `normalize.go`, `filter.go`, CLI `cmd/profanity` (check/censor/eval/bench).
   Сборка и `go vet` — с первого раза. `eval` на `sample.tsv` сразу 20/20 (P=R=F1=1.0).
3. **Тесты** — позитив/негатив по каждому корню, каждой маскировке, каждой ловушке, отдельно `Censor`,
   позиции матчей, CLI (формат JSONL, eval) + `testdata/hard.tsv` (66 своих трудных примеров: 32 мат, 34 ловушки).
4. **Прогоны тестов до зелёного — 3 итерации:**
   - #1: 3 падения:
     - `муденый` — придуманное мной слово, не мат; убрал из теста (это была ошибка теста, а не правил);
     - `Censor("пи3дец и п-и-з-д-а")` → окно начиналось с союза «и» и обрывалось на «д» → добавил
       сужение окна слева и расширение вправо;
     - `sh i t happens` не ловилось: английские правила в окнах были разрешены только для одиночных букв →
       разрешил, если все фрагменты ≤2 букв (`U.S. hit` по-прежнему чист).
   - #2: 1 падение — расширение вправо ещё не было реализовано (`п-и-з-д` без `а`) → правило «вправо по
     одиночным буквам, но не через предлог после пробела».
   - #3: всё зелёное.
5. **Линтеры** — `gofmt -l .` пусто, `go vet` чисто, `staticcheck` (2026.2.2) — 0 замечаний.
6. **Дополнительные трудные примеры** (≈90 ручных проб помимо hard.tsv) — найдено и исправлено:
   - `Matsushita/Yamashita/Kinoshita` давали `shit` → исключение `[a-z]shita`;
   - `ебонит` → исключение;
   - `спидорасило` не ловилось → приставка `с` для «пидор» (`спидометр` чист);
   - `бл.я.дь` цензурилось как `бл.я` → хвост ≤3 букв через непробельный разделитель присоединяется.
   После этих правок (и новых тестов на них) тесты прошли с первого прогона.
7. **Замеры** — `bench`: ~111–116 тыс. строк/с; `check --input` на 100 000 строк: 0.45 с (~220 тыс. строк/с).
8. **Документация** — README (подход, примеры, ограничения, команды), DECISIONS.
