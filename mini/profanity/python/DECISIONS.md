# DECISIONS

| Вопрос | Решение | Почему |
|---|---|---|
| Как бороться с ложными срабатываниями на подстроках? | Якорение корня к началу слова или к белому списку приставок, а не чёрный список исключений | Белый список приставок обобщается на скрытую выборку (`учебник`, `потребитель`, `хлеб`… отсекаются одним правилом), список исключений — нет |
| Нормализовать ли гомоглифы заранее в одну строку? | Нет: каждая буква корня → класс символов-двойников в регекспе | Неоднозначные двойники (`b`=б/в, `h`=н/х, `u`=и/у) не требуют перебора вариантов, а позиции в исходном тексте сохраняются |
| Схлопывать ли повторы букв? | Нет, `+` после каждого класса буквы | Не ломает слова с двойными буквами и сохраняет спаны; `shiitake` при этом не превращается в `shit…` |
| Применять ли кириллические правила к чисто латинским словам? | Нет (только если в слове есть кириллица или цифры/символы-заменители); для латиницы — отдельные консервативные правила транслита | Иначе `ebay`, `ebony`, `Xue`, `Huy` давали бы срабатывания |
| Как склеивать слова через дефис? | Сначала проверка частей отдельно, затем склейка — только если есть часть длиной ≤ 2 | Ловит `п-и-з-д-а`, но не склеивает `eBay-магазин`; `Бля-буду` даёт точный спан `Бля` |
| Буквы через пробел | Склеиваем ≥ 3 однобуквенных токена подряд, ищем корень с каждого смещения | 2 буквы — слишком много шума от предлогов (`и`, `в`, `с`, `я`) |
| Что заменять в `censor`? | Всё найденное слово (включая приставки/суффиксы и пробелы между буквами) → первая буква + `***` | Так сказано в ТЗ; частичная цензура оставляла бы читаемые хвосты |
| `*` внутри слова | И как разделитель (`х*у*й`), и как замена гласной (`п*зда`, `f*ck`) | Обе формы частые; `***` без букв токеном не является, поэтому вывод `censor` повторно не срабатывает |
| `сука`, `гандон` и т.п. | Не включены; добавлены только `манда` и `ёпт/епта` | ТЗ задаёт список корней; `сука` — также литературное слово. `манда` добавлена, т.к. ловушки ТЗ (`команда`, `мандарин`) подразумевают этот корень |
| `бляха` | Не мат | Обычное слово (пряжка); `бля` без `д` ловится только как `бля`/`блять`/`блят…` |
| `Ебург`, `ебонит` | Исключены отрицательным lookahead | Сленговый топоним и частая опечатка «эбонит» |
| Какой `matches` в CLI | Список исходных слов (`word`) | ТЗ: `"matches": ["..."]`; подробности (start/end/root) — в библиотечном `check` |
| Пустые строки входа | Выводятся как `profane: false` с сохранением номера строки | «Одна строка вывода на строку входа» |
| `eval`: строки `#…`, пустые, без TAB | Пропускаются (с предупреждением в stderr для битых) | Позволяет комментировать TSV (`data/hard.tsv`) |
| Сборка | hatchling + `uv`, скрипт `profanity`; runtime-зависимостей нет | Также работает `PYTHONPATH=src python -m profanity_filter` |
| Кеш | `lru_cache` на классификацию слова (65 536) | Реальный текст повторяет слова, даёт ~+40% к скорости |
