# profanity-filter (Python 3.12)

Фильтр нецензурной лексики на регулярных выражениях (без ML и внешних API):
русский мат (корни `хуй/хуе/хуя`, `пизд`, `еб/ёб`, `бля/блядь`, `мудак/мудил`,
`пидор/пидар/пидорас`, `залуп`, дополнительно `манда`) и базовый английский
(`fuck`, `shit`, `bitch`, `cunt`, `motherfucker`, `bullshit`). Зависимостей
во время выполнения нет — только стандартная библиотека.

## Запуск

Из каталога проекта (`mini/profanity/python/`):

```bash
# проверка файла (точная команда для независимой проверки)
env -u HTTPS_PROXY -u HTTP_PROXY uv run profanity check --input <file>

# без --input текст читается из stdin
echo "Ну ты и мудак" | env -u HTTPS_PROXY -u HTTP_PROXY uv run profanity check

# цензура stdin -> stdout
echo "Какой мудак тут, бля" | env -u HTTPS_PROXY -u HTTP_PROXY uv run profanity censor
# Какой м*** тут, б***

# оценка на размеченной выборке (label<TAB>text, label 1/0)
env -u HTTPS_PROXY -u HTTP_PROXY uv run profanity eval --input data/sample.tsv
env -u HTTPS_PROXY -u HTTP_PROXY uv run profanity eval --input data/hard.tsv
```

Альтернатива без uv (зависимостей нет): `PYTHONPATH=src python3.12 -m profanity_filter check --input <file>`.

Формат `check` — JSONL, одна строка на строку входа:

```json
{"line": 3, "text": "x у й с ним", "profane": true, "matches": ["x у й с"]}
```

`eval` печатает TP/FP/FN/TN, precision, recall, F1 и список ошибок (`FP`/`FN` с номером строки).

## Библиотека

```python
from profanity_filter import check, censor

check("Ну и мудак, бля")
# {'profane': True, 'matches': [
#    {'word': 'мудак', 'start': 5, 'end': 10, 'root': 'мудак'},
#    {'word': 'бля', 'start': 12, 'end': 15, 'root': 'бля'}]}
censor("иди нахуй!")  # 'иди н***!'
```

`start`/`end` — смещения в исходной строке (`text[start:end] == word`).
`censor` заменяет слово целиком на первую букву + `***`.

## Подход

1. **Токенизация.** Слово — последовательность букв/цифр и символов-заменителей
   (`@`, `$`, внутри слова `!`, `|`). Части слова, склеенные разделителями
   (`. - _ * ' ~ /`, мягкий перенос, zero-width), образуют один составной токен:
   `х.у.й`, `п-и-з-д-а`, `х​у​й`.
   Сначала проверяется каждая часть отдельно (точный спан: `Бля-буду` → `Бля`),
   затем — склейка, но только если есть часть длиной ≤ 2 (иначе `eBay-магазин`
   склеился бы в «ебay…»). `*` дополнительно трактуется как пропущенная гласная: `п*зда`, `f*ck`.
2. **Буквы через пробел.** Серия из ≥ 3 однобуквенных токенов, разделённых
   пробелами/разделителями (`х у й`, `б . л . я`), склеивается; корень ищется с
   каждого начального смещения серии (`и я х у й` → `х у й`).
3. **Нормализация.** `lower()`, `ё → е`. Повторы букв не схлопываются заранее —
   в шаблоне каждая буква корня имеет квантификатор `+` (`бляяяять`, `ббббля`, `fuuuck`).
4. **Похожие символы.** Каждая буква корня разворачивается в класс
   символов-двойников: `х→[хxh]`, `у→[уyu]`, `е→[еe]`, `о→[оo0]`, `а→[аa@]`,
   `р→[рp]`, `с→[сc$]`, `к→[кk]`, `м→[мm]`, `н→[нh]`, `в→[вb8]`, `б→[б6b]`,
   `з→[з3z]`, `и→[иu1iі!|]`, `п→[пn]`, `я→[я9]`, `ч→[ч4]` и т.д. Неоднозначность
   (`b` = `б` или `в`, `h` = `н` или `х`) решается самим регекспом, без перебора вариантов.
   Для английских корней — leet-классы (`i→[i1!|]`, `s→[s$5]`, `o→[o0]`…), а
   кириллические двойники в латинском слове (`fuсk` с кириллической `с`) проецируются в латиницу.
5. **Якорение корней — главный инструмент против ложных срабатываний.**
   * Корни, которые не встречаются внутри обычных слов, ищутся где угодно:
     `пизд`, `бляд`, `залуп`, `муд(ак|ил|ач|озвон…)`, `fuck`, `bitch`.
   * Опасные короткие корни должны стоять в начале слова или после разрешённых
     приставок (до 3 подряд):
     `еб` — `за/на/вы/у/по/до/от/при/про/пере/недо/не/ни/о/долбо…`, а `с/в/под/от/об/раз/из/вз`
     только с `ъ/ь` (`съебись`, но `себя`, `вебинар`); поэтому `учебник`, `потребитель`, `хлеб`, `небо` чисты.
     `ху[йеяюи]` — `на/по/ни/не/до/за/о/от/с…` (`нахуй`, `охуеть`), но `застрахуй`, `Чихуахуа` чисты.
     `пид[оа]р` — в начале или после `о/от/за/рас/вы/у/на` (`скипидар` чист).
     `бля` без `д` — только как целое слово `бля`/`блять`/`блят…` (`рубля`, `сабля`, `оскорблять`, `бляха` чисты).
     `манда` — только с перечнем окончаний (`команда`, `мандарин`, `мандат` чисты).
     `shit` — только с известными приставками/суффиксами (`shiitake` чист), `cunt` — в начале слова (`Scunthorpe` чист).
6. **Транслит** (только для полностью латинских слов): `pizdec`, `blyat`, `nahuy`,
   `zaebal`, `xyu`… с консервативными правилами (`Huy`, `Xue`, `ebay`, `debate` чисты).
7. **Производительность.** Все правила одного алфавита собраны в один
   регексп с именованными группами и компилируются один раз при импорте;
   результат классификации слова кешируется (`lru_cache`, 65 536 слов).

## Производительность

`uv run python scripts/bench.py` (100 000 строк по 5–15 слов, Apple Silicon, Python 3.12):

| корпус | строк/с |
|---|---|
| реалистичный (словарь повторяется, кеш работает) | ~95–105 тыс. |
| все слова уникальные (кеш бесполезен, худший случай) | ~60–74 тыс. |
| CLI `check` целиком (чтение + JSON-вывод), реалистичный корпус | 100 000 строк за ~1.3 с ≈ 75 тыс. |

## Ограничения

* Словарь корней фиксирован ТЗ (+`манда`, `ёпт`). `сука`, `гандон`, `шлюха`, `дрочить` и пр. не ловятся.
* Буквы через пробел распознаются от 3 одиночных букв подряд; смешанное `пиз дец`, `ху йня` не ловится.
* Звёздочка заменяет только гласную (`п*зда`) или служит разделителем; `f**k` — частный случай;
  `***` целиком не считается матом.
* Пропущенные/лишние буквы (`блиать`, `пзд`) и фонетические замены (`пезда`→ловится, `писда` — нет) покрыты частично.
* Возможны ложные срабатывания на редких именах собственных (`Ебоев`, `Хуйзинга`) и на
  склейке через разделитель без пробела, если части короткие.
* Транслит покрыт базово; английский — только 6 корней из ТЗ.
* Контекст не учитывается: `хуй` в цитате или лингвистической статье тоже будет найден.
