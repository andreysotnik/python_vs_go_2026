Ты — senior-разработчик. Напиши на Python 3.12 библиотеку и CLI для проверки текста на нецензурную лексику с помощью регулярных выражений (без ML и внешних API).

## Что считать нецензурным
- Русский мат и производные от корней: «хуй/хуе/хуё/хуя», «пизд», «еб/ёб» (ебать, заебал, ёбаный, уебок, выебываться, еблан…), «бля/блядь», «мудак/мудил», «пидор/пидар/пидорас», «залуп» — во всех формах: приставки, суффиксы, окончания, падежи.
- Базовый английский: fuck, shit, bitch, cunt, motherfucker, bullshit.

## Обход маскировки (обязательно)
- Латинские буквы, похожие на кириллические: x→х, y→у, e→е, o→о, a→а, p→р, c→с, k→к, m→м, h→н, b→в…
- Цифры и символы: 0→о, 3→з, 6→б, 1→и, @→а, z→з…
- Разделители между буквами: `х у й`, `х.у.й`, `п-и-з-д-а`.
- Повтор букв: `бляяяять`, `ббббля`.
- Регистр, ё/е.

## Ложные срабатывания недопустимы
Обычные слова, внутри которых есть «опасная» подстрока, не должны считаться матом: «команда», «мандарин», «оскорблять», «употреблять», «застрахуй», «скипидар», «учебник», «потребитель», «рубля», «сабля», «Scunthorpe», «shiitake», «assassin» и подобные. Цель — высокая точность и полнота одновременно.

## Интерфейс
- Библиотечная функция: `check(text) → {profane: bool, matches: [{word, start, end, root}]}` и `censor(text) → text`, где найденные слова заменены на `***` с сохранением первой буквы.
- CLI: `<запуск> check --input file.txt`. Без `--input` текст читается из stdin. Каждая строка входа — отдельный текст. Вывод — JSONL, одна строка на строку входа: `{"line": N, "text": "...", "profane": true, "matches": ["..."]}`.
- CLI: `<запуск> censor` — читает из stdin и выводит текст с цензурой.
- CLI: `<запуск> eval --input data/sample.tsv`. Формат TSV: `label<TAB>text`, где label равен 1 (мат) или 0. Выводит precision, recall, F1 и список ошибок.
