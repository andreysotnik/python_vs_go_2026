# Журнал работы

## Этапы

1. **Разбор ТЗ и окружения.** go1.27.3; в Docker локально есть `golang:1.26-alpine` и
   `distroless/static-debian12:nonroot` — выбраны они (без лишних загрузок). Mailpit пришлось скачать.
2. **Каркас.** `go mod init`, зависимости `robfig/cron/v3`, `gopkg.in/yaml.v3` через proxy.golang.org.
   Пакеты: config, schedule, tmpl, mailer (message/smtp/retry), state, runner, cmd/mailer.
   Сборка + `go vet` + `gofmt` — чисто с первого раза.
3. **Тесты.** Фейковый SMTP-сервер `internal/smtptest` (хуки на ответы по командам).
   Модульные: cron/таймзоны/DST, шаблоны, конфиг/окружение, MIME/RFC 2047/вложения,
   повторы и классификация ошибок, состояние, дедупликация, graceful shutdown, демон с фейковыми часами
   (пропуски). Интеграционный: `run(["once", ...])` → фейковый SMTP → проверка получателей,
   кириллической темы, тела, вложения байт-в-байт, отсутствия дубля при повторе.
4. **Docker.** `docker compose up --build`, `once` внутри контейнера, проверка через API Mailpit,
   повторный `once` (дубля нет), `once` с хоста на порт 21025, `docker compose stop` (SIGTERM — корректный выход),
   `docker compose down -v --rmi all`.
5. **Ручная проверка демона на хосте**: задача `* * * * *`, 65 с — письма в 16:31:26 (текущая минута при старте)
   и 16:32:00.001 (начало минуты), SIGTERM — выход 0.

## Ошибки и исправления (итерации)

| # | Что упало | Причина | Исправление |
