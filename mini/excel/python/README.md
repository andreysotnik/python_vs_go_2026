# sales-report

Консольная утилита: читает Excel-выгрузку продаж (`Sales` + `Targets`), чистит данные
по правилам ТЗ, считает агрегаты и строит PNG-графики и HTML-отчёт.

Стек: Python 3.12, `openpyxl` (чтение xlsx), `matplotlib` (графики), `decimal`
(точная арифметика денег), `pytest`, `ruff`, `mypy --strict`. Управление окружением — `uv`.

## Установка

```bash
uv sync            # создаёт .venv и ставит зависимости (вкл. dev: pytest, ruff, mypy)
```

> За корпоративным прокси, который ломает PyPI, все команды `uv` запускайте так:
> `env -u HTTPS_PROXY -u HTTP_PROXY uv ...`

## Запуск

Из каталога проекта (точная команда для проверки):

```bash
uv run sales-report --input data/sales.xlsx --out out/
```

Альтернатива: `uv run python -m sales_report --input data/sales.xlsx --out out/`.

Опции:

| Опция     | Описание                                                                  |
|-----------|---------------------------------------------------------------------------|
| `--input` | путь к .xlsx с листами `Sales` и `Targets` (обязательно)                   |
| `--out`   | каталог для результатов, создаётся при необходимости (обязательно)         |
| `-q`      | не печатать каждую пропущенную строку в stderr (они всё равно в skipped.csv) |

Коды выхода: `0` — успех, `2` — ошибка входных данных (нет файла, не xlsx, нет листа,
неверный заголовок, битая строка плана) — сообщение в stderr; `2` также у argparse
при неверных аргументах.

## Результат (`out/`)

| Файл                    | Содержимое                                                 |
|-------------------------|------------------------------------------------------------|
| `summary.json`          | агрегаты строго по структуре ТЗ                             |
| `skipped.csv`           | `row_number, order_id, reason` — все пропущенные строки     |
| `revenue_by_month.png`  | линия выручки по месяцам                                   |
| `revenue_by_region.png` | столбцы по регионам                                        |
| `category_share.png`    | кольцевая диаграмма долей категорий                        |
| `top_products.png`      | горизонтальные столбцы, топ-10 товаров                     |
| `plan_vs_fact.png`      | сгруппированные столбцы план/факт + % выполнения           |
| `report.html`           | одна страница: KPI, все графики, таблицы план/факт и топ-10 |

Пример вывода в stderr:

```
WARNING: строка 53 пропущена (ORD-00052): дата не разбирается: 'когда-то'
...
INFO: Готово: валидных строк 4833, пропущено 200, выручка 207149040.50. Результаты: .../out
```

Фрагмент `summary.json` на `data/sales.xlsx`:

```json
{
  "valid_rows": 4833,
  "skipped_rows": 200,
  "total_revenue": 207149040.5,
  "plan_vs_fact": [
    {"region": "Екатеринбург", "fact": 36125409.0, "target": 31870000.0, "completion_pct": 113.35}
  ]
}
```

## Правила очистки (кратко)

1. Полностью пустые строки (все ячейки пусты/пробелы) игнорируются.
2. Дубликат `order_id` — пропуск; учитывается только первое вхождение, даже невалидное.
3. `order_date` — дата Excel (datetime или серийный номер) либо текст `DD.MM.YYYY`.
4. `quantity` — только числовая ячейка с целым значением > 0.
5. `unit_price` — число > 0 или текст с `.`/`,` как десятичным разделителем.
6. `discount` — доля 0..1 или `"15%"`; пусто → 0; вне диапазона → пропуск.
7. `region` обрезается по краям.
8. Выручка = `quantity * unit_price * (1 - discount)` в `Decimal`, округление (half-up)
   до 2 знаков только при выводе.

Если в строке несколько ошибок, в `reason` перечисляются все через `; `.
Неочевидные решения — в [DECISIONS.md](DECISIONS.md).

## Структура

```
src/sales_report/
  cli.py         # argparse, логирование, конвейер run()
  reader.py      # чтение xlsx, проверка листов/заголовков, разбор Targets
  cleaning.py    # правила очистки (чистые функции) + clean_rows()
  aggregate.py   # агрегаты, Summary -> dict для summary.json
  charts.py      # 5 PNG (matplotlib OO API, без pyplot)
  report.py      # summary.json, skipped.csv, report.html
  formatting.py  # числа с разделителями тысяч, подписи месяцев
tests/           # unit + integration
```
