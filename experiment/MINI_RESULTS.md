Наблюдения:
- Excel: Go в 3.3× дольше и в 3× дороже. Причины: gonum/plot без кольцевой диаграммы (нарисовал сам), паника на пустых данных, ручная вёрстка подписей; golangci-lint несовместим с go1.27 (окружение). У Python matplotlib + openpyxl закрыли всё «из коробки».
- Рассылка: паритет. Оба написали cron-логику, дедупликацию, graceful shutdown; Go — stdlib net/smtp, distroless; Python — свой cron-парсер, aiosmtpd в тестах. Go-агент нашёл гонку с помощью `go test -race`.
- Мат-фильтр: Go чуть точнее (поймал «бл@ть»), несмотря на RE2 без lookahead/lookbehind — пришлось проверять слово целиком. Оба дали FP на «Ебенезер Скрудж». Скорость: Go CLI ~220k строк/с, Python ~75k строк/с.
- Код на Go длиннее на 53% (без тестов).
